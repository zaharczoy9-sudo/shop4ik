# shop4ik — Telegram Mini App магазин + админка

## Быстрый запуск для демо (без Telegram)
```
node bot.js
```
- Магазин: `http://localhost:3000/`
- Админка: `http://localhost:3000/admin` (пароль по умолчанию `demo123`)

Оформите заказ в магазине — он мгновенно появится в админке со звуком и всплывающим уведомлением.
Кнопка **«➕ Тестовый заказ»** в админке создаёт заказ одним нажатием (удобно показывать заказчику).

## Переменные окружения (Railway)
| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота (без него — демо-режим без Telegram) |
| `WEBAPP_URL` | https-адрес приложения на Railway |
| `MANAGER_CHAT_ID` | ID чата/человека, куда приходят уведомления о заказах |
| `ADMIN_IDS` | ID админов через запятую (кто может жать кнопки статусов в Telegram) |
| `ADMIN_PASSWORD` | пароль веб-админки `/admin` (обязательно смените!) |

## Что умеет
- Заказ из Mini App уходит на сервер по HTTP (`/api/order`), цены и итог пересчитываются на сервере.
- Уведомление о заказе: в веб-админке (live, звук) + в Telegram менеджеру с кнопками статусов.
- Смена статуса из админки или из Telegram синхронизируется в обе стороны; клиент получает сообщение о статусе.
- Админка: заказы, статусы, товары (наличие, цена, добавление/удаление), настройки магазина.
- Бот-команды: `/admin`, `/orders`, `/price`, `/delivery`.

Данные хранятся в `data/store.json` (на Railway подключите Volume, иначе файл сбрасывается при деплое).
